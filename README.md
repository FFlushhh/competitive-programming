# CompetitiveProgramming

競技プログラミングの学習・コンテスト参加で使用するコード、アルゴリズムの実装例、開発環境設定を管理するリポジトリです。

## Directory

- `AtCoderBeginnerContest/` - AtCoder Beginner Contestなどの問題解答・練習コード
- `Library/atcoder/` - AtCoder Library（ACL）
- `Techniques/` - アルゴリズム・データ構造・実装テクニックのサンプルコード
- `TechFUL/` - TechFUL関連のコード
- `.vscode/` - VS Codeのプロジェクト設定・C++コードスニペット

## VS Code Snippets

競技プログラミングで使用するC++コードスニペットは、以下のファイルを正本として管理します。

```text
.vscode/cpp.code-snippets
```

リポジトリをVS Codeのワークスペースとして開くことで、Windows・macOSなど異なる環境でも同じプロジェクトスニペットを利用できます。
